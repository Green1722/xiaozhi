## 最新进度（2026-11-06）

已在华为云验证电脑模拟测量设备经 IoTDA 上报，自动转发至开发者空间的体检服务并写入 SQLite。小智通过 MCP 查询并实机播报了同编号的两组记录。A 为 175 cm、70 kg、BMI 22.86，B 为 168 cm、62 kg、BMI 21.97。

同一 MQTT 报文重传后仍只保留一条业务记录。指定编号不存在时，小智提示未找到。临时 HTTPS 入口关闭后，小智提示无法查询。本地云端项目测试 39 项通过。仓库已包含离线补传队列和双样本复跑脚本。验收后已停用测试转发规则并关闭临时托管。

## 使用说明

这是多个历史子项目的整理快照，尚未验证为统一可运行系统。构建缓存、虚拟环境、供应商压缩包、工具安装包、历史聊天日志与本地私密配置未提交；主压缩包以源码形式保存。原始资料保留在本地。

连接凭据已在上传副本中替换为 `REPLACE_ME`，运行前需自行配置。上传前仅做静态与文件检查，没有构建固件或进行硬件验收。第三方源码保留原有 LICENSE；不将第三方代码声明为本队原创，也不额外统一授权。
