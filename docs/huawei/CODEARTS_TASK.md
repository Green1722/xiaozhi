# 码道开发与部署任务单

此任务单供团队在已登录的华为云码道环境中执行。本文件的存在不证明已使用码道，也不替代运行日志。

## 可以交给码道的真实增量

将以下需求复制到码道，先审查方案再执行：

> 阅读docs/huawei/官方规则核对_2026-11-04.md、智能体检华为云迁移方案.md与cloud/health_exam。当前已有双ESP32板、MQTT和Python MCP体检服务。请先运行现有测试，检查仪器record_id及接收时间在重传、重启时的稳定性，提出最小改动。然后实现有界的SQLite持久离线上传队列：上报失败保留、重试不重复、冲突不覆盖、恢复后能查明结果；新增测试覆盖断网重启补传和两台仪器同时上报。保留旧MQTT与播报路径，不烧写固件，不开通计费资源，不捏造设备播报回执。完成后输出代码差异、实际命令和结果。

该增量尚未在本轮实现，明确留给真实码道实践；若需求优先级变化，可换成真实设备回执、RDS迁移验证等同等具体任务。

## 免费云端运行任务

> 使用平台已有智能体与Skills，先只读核对我的开发者空间免费环境、剩余额度、网络访问和数据留存条件。选择无需支付的运行方式部署cloud/health_exam，先只用synthetic样本。不要创建会计费的资源；若没有零付费方案，列出阻塞与组委会资源申请入口。不要将SQLite称为RDS。部署后真实访问healthz、上传一条模拟记录、通过页面查询并重启验证；说明访问链接是否需要登录及是否能用于决赛演示。输出资源信息、命令、日志和复现步骤，屏蔽密钥。

官方赛题提供的[Skills部署案例入口](https://gitcode.com/weixin_43883336/auto-deploy/blob/main/auto-deploy-case-study.md)用于了解流程，运行前由码道读取并核查所需资源与费用；本轮未安装或运行该第三方Skill。也可从官网[码道入口](https://developer.huaweicloud.com/codeartsco.html?source=dmzntcompetition)和[AI开发者空间](https://devstation.developer.huaweicloud.com/aidevspace?utm_source=competition&utm_medium=ict&utm_campaign=innovation)进入。
