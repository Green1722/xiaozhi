# ESP32 双板飞线与配网安全指南

---

## 1. 适用范围与角色

- **测量板（仪器 ESP32）**：连接身高体重仪，采集数据并上报 MQTT。
- **小智板（xiaozhi-esp32-main）**：连接小智云，接收唤醒并语音播报。

---

## 2. 飞线接线（只做必要连接）

### 2.1 身高体重仪 → 测量板

| 仪器端 | 测量板引脚 | 说明 |
|---|---|---|
| TXD | GPIO16 (RX2) | 仪器发，测量板收 |
| GND | GND | 必须共地 |

- 仅需 2 根线：`TXD + GND`
- 仪器 RXD 不接
- 串口参数：`115200 8N1`

### 2.2 测量板 → 小智板

| 测量板 | 小智板 | 说明 |
|---|---|---|
| GPIO47 | GPIO38 | 低电平触发唤醒（约 200ms） |
| GND | GND | 必须共地 |

- 仅需 2 根线：`GPIO47 + GND`
- 两板**独立供电**，禁止互连 3.3V/5V 电源线

### 2.3 飞线总数与验收

- 全系统共 4 根飞线：
  - 仪器侧：`TXD`、`GND`
  - 板间：`GPIO47`、`GND`
- 首次上电前必须复核：
  - 没有 5V/3.3V 误连
  - 所有 GND 已可靠连接

---

## 3. 配网流程（推荐顺序）

### 3.1 测量板配网（typec线插右边接口）

1. 上电后自动尝试已配置热点。
2. 若全部失败，进入 SmartConfig（手机下载ESP-Touch）。
3. 连网成功后再启动 MQTT 与 MCP。

**注意**：ESP32 仅支持 2.4GHz，手机热点需开启 2.4G 兼容模式。

### 3.2 小智板配网

typec线插右边接口，插入时按芯片板右侧小按钮进入配网模式，手机连接xiaozhi热点配网。

### 3.3 联调顺序（避免误判）

1. 先通电 + 飞线验收
2. 测量板联网成功
3. 小智板联网成功
4. MQTT 连接成功
5. MCP 连接成功
6. 做一次实测（看 GPIO 唤醒 + 播报链路）

## 6. 快速检查清单

### 6.1 接线

- [ ] 仪器 TXD → 测量板 GPIO16（RX2）
- [ ] 仪器 GND → 测量板 GND
- [ ] 测量板 GPIO47 → 小智板 GPIO38
- [ ] 测量板 GND → 小智板 GND
- [ ] 未连接任何板间 3.3V/5V 电源线

### 6.2 配网与链路

- [ ] 两板均已连接 2.4GHz WiFi
- [ ] MQTT 已连通（主题收发正常）
- [ ] MCP 已连通（工具调用成功）
- [ ] 测量完成后 GPIO47 低脉冲可触发小智播报

### 6.3 安全

- [ ] 仓库中无真实 Token/密码
- [ ] 日志与截图已脱敏
- [ ] MQTT 已启用认证（生产建议 TLS + ACL）

## 7. 常见故障与排查

| 现象 | 优先排查 |
|---|---|
| 测量板连不上网 | 是否 2.4GHz、SmartConfig 是否超时 |
| MQTT 连接失败 | Broker 地址端口、账号密码、ACL、TLS 时间同步 |
| MCP 401 | Token 失效/泄露，重签发后更新 |
| 小智不播报 | GPIO47→GPIO38 是否接对、是否共地、工具是否被调用 |
| 偶发触发失败 | GND 接触不良、线过长干扰、电平不稳 |
