# 小智 AI 对话记录器

连接小智服务器，实时记录对话内容到 txt 文件。

## 安装

```bash
pip install websockets
```

## 运行

```bash
cd tools
python chat_recorder.py
```

## 输出

程序自动创建 `chat_日期_时间.txt` 文件：

```
==================================================
小智 AI 对话记录
开始: 2026-03-31 14:30:52
==================================================

[14:30:55] 用户: 你好小智
[14:30:58] AI: 你好！有什么可以帮助你的吗？

--- 2026-03-31 ---

[14:31:10] 用户: 今天天气怎么样
[14:31:15] AI: 今天天气晴朗，气温20到25度。

==================================================
结束: 2026-03-31 15:30:00
==================================================
```

## 说明

- 无需配置服务器，使用小智官方服务器
- 无需数据库，所有记录直接保存到 txt
- 按 Ctrl+C 停止并保存文件
